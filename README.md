
# IDS Next Hotel Integration Demo

A Python-based demonstration of integrating a hotel Property Management System (PMS) with an external application.

## Overview

This project demonstrates a proposed integration architecture for IDS Next using FastAPI, realistic sample hotel data, and a lightweight web dashboard.

## Features

- Simulated hotel reservations, guest profiles, room status, and folio charges
- FastAPI endpoints for retrieving sample PMS data
- Reservation synchronization with a simulated external system
- Simple HTML, CSS, and JavaScript dashboard
- Modular adapter design to support a future vendor-approved integration
- Planned automated testing, validation, logging, and error handling

## Technology Stack

- Python
- FastAPI
- HTML, CSS, and JavaScript
- Pytest
- JSON sample data

## Important Note

This is a demonstration project. It does not currently connect to a live IDS Next environment. Real integration depends on access to the appropriate vendor documentation, approved credentials, and required permissions. All sample data is fictional.

## Project Goal

Demonstrate the feasibility and architecture of a hotel PMS integration before connecting to a real environment.
